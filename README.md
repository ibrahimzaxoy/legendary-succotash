# Restaurant Management System

A platform unifying three ordering channels — outside mobile ordering,
in-restaurant table QR/barcode ordering, and waiter-assisted ordering — into
one order pipeline that routes items to the correct kitchen station
(Pizza, Hookah, Grill, Bar, etc.) in real time, with accounting and delivery
built in.

See [`docs/IMPLEMENTATION_PLAN.md`](docs/IMPLEMENTATION_PLAN.md) for the full
architecture, technology stack, data model, order flow, and phased roadmap.
